Ever been caught off guard by a date request and found yourself completely on the fence? Stop agonizing over the text back and let the math decide.

Simply download the `worth_my_time.html` file and open it in any web browser (like Chrome or Safari) to use the "Worth My Time?" Calculator. It takes the emotion out of the equation, objectively assessing your energy, schedule, and curiosity to tell you if this hangout is actually a green light—or a hard pass!


### Scoring Model

The final score is calculated using a weighted average of four key metrics. Since each variable is scored on a 1-5 scale, we divide the sum by 5 to normalize the final output to a 0.0 - 1.0 scale (representing 0% to 100%).

$$ Score = \frac{(E \times W_E) + (T \times W_T) + (X \times W_X) + (P \times W_P)}{5} $$

#### Variables (Inputs)
Each variable is evaluated on a scale of **1 to 5**:
* E (Energy)
* P (Spark Potential)
* X (Experience)
* T (Time)


#### Weights (Constants)
The weights determine the relative importance of each variable and sum to 100% (1.0):
* **W_E (Energy):** 0.35 
* **W_P (Spark Potential):** 0.30 
* **W_X (Experience):** 0.20 
* **W_T (Time):** 0.15

#### Example Calculation
If an item scores a 4 in Energy, 5 in Spark, 3 in Experience, and 2 in Time:
* **Numerator:** `(4 * 0.35) + (2 * 0.15) + (3 * 0.20) + (5 * 0.30)` = `1.4 + 0.3 + 0.6 + 1.5` = `3.8`
* **Final Score:** `3.8 / 5` = **0.76 (76%)**
